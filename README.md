## 🚀 Overview

This project is part of the **Final Year Project (PFE)** for obtaining the **Bachelor’s degree in Information Systems Engineering and Software**.

DAWN&SEA is a platform that:
- Lists Algerian wilayas  
- Provides tourism-related details  
- Offers detailed pages accessible after user authentication
